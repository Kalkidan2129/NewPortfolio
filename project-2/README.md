
# Revenue Forecasting and Performance Analysis of Vodafone Qatar (2021–2023)

## Project Overview

This project transformed Vodafone Qatar's telecom data into a consolidated, machine-learning-ready dataset using NexusMax, Python, and Microsoft Fabric. It enabled advanced revenue forecasting, churn analysis, and performance tracking through interactive dashboards, empowering finance and strategy teams with actionable insights. The solution improved decision-making by revealing hidden patterns in customer behavior and network performance.

---

## Business Problem

Vodafone Qatar faced challenges in understanding regional and segment revenue fluctuations due to fragmented data and unpredictable churn rates. This lack of consolidated insight hindered accurate forecasting and budget planning. Finance and strategy teams required a unified view of revenue, subscribers, churn, and network metrics to make confident, data-driven decisions.

---

## Objective

- Create a unified, clean, and enriched dataset for advanced analytics
- Improve quarterly revenue forecasting accuracy to optimize budget allocation
- Reduce churn in key customer segments to protect recurring revenue

---

## Tools & Technologies

- NexusMax
- Python
- Microsoft Fabric
- Power BI
- Numtra
- Pandas

---

## Project Workflow

- Collect and clean Vodafone Qatar telecom data from 2021-2023
- Engineer and enrich dataset with key KPIs and time-based features
- Develop supervised regression models for quarterly revenue forecasting
- Create interactive Power BI dashboards for performance visualization
- Deploy unified ML-ready dataset and dashboards for business use

---

## Key Insights

- Total revenue increased 14% quarter-over-quarter, driven largely by Doha region
- Churn rate for high-value prepaid customers rose by 0.3% QoQ, impacting revenue stability
- Network availability remained high at 99.95%, supporting customer retention efforts
- Churn in Mobile Postpaid and Fixed Broadband segments exceeded overall churn, risking $8–12K annual revenue loss
